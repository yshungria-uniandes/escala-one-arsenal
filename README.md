# Arsenal Vibe Coding

Página estática de una sola vista: los prompts reutilizables extraídos de la Q&A de
Vibe Coding (19 ago 2026). Referencia personal de Yojan.

- **En vivo**: https://prompts.escalaone-lab.com
- **Stack**: HTML plano + nginx (Dockerfile). Sin build, sin runtime.
- **Deploy**: Coolify (VPS Hostinger), Cloudflare al borde. Público.

Para editar el contenido, se toca `index.html` y se hace push a `main` (auto-deploy Coolify).
